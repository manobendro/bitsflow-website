We set out to build the learning board we always wished existed: as approachable
as the BBC micro:bit, but as its own board — with **full-color output**, modern
wireless, and room to grow into real projects. (Bitsflow is inspired by the
micro:bit; it is not a micro:bit and is not compatible with micro:bit hardware.)

## Color changes everything

The 5×5 **RGB** matrix turns simple programs into something kids actually want to
show off — animated emoji, color-coded sensor readouts, tiny games.

```python
from bitsflow import display, Color

display.scroll("Hi!", color=Color.CYAN)
```

## Wireless out of the box

With **BLE** and **Wi-Fi** built in, your projects can talk to phones, dashboards
and the cloud — no extra modules required.
